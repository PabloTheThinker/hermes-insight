# Changelog

## 0.1.0 — 2026-08-09

- Public release as **Hermes Insight** (brief working title: Pattern Lattice)
- Package: `hermes_insight` · CLI: `hermes-insight` / `hinsight`
- Core harness: ingest, match, search, cycle, distill, extrapolate, analogy, feedback, evolve
- Multi-lens recognition (template / prototype / feature / hybrid) with light stemming
- SQLite + FTS5 pattern graph store
- Cross-domain linking and cluster synthesis
- Hermes skill pack + plugin skeleton
- Research and architecture docs
- Offline demo and pytest suite
- Independent companion harness for agents (including Hermes Agent); not an official Nous product
