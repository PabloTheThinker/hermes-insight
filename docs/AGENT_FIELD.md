# Agent field ontology

Hermes Insight is oriented to the **AI agent / model world**.

## Native nouns

agent · model · tool · skill · plugin · profile · context · memory · prompt ·
delegation · toolset · inference · embedding · session · harness · multi-agent ·
compartment · eval · policy

## Pattern kinds

Includes `agent`, `model`, `tool`, `skill`, `prompt` plus classic cognitive kinds.

## Link kinds (agent graph)

`uses_model` · `has_skill` · `delegates_to` · `calls` · `shares_context`
plus similar/part_of/enables/analogy/…

## Fabric kinds

| fabric | meaning |
|--------|---------|
| profile | agent identity |
| model | model route |
| skill | SKILL.md package |
| plugin | harness plugin |
| tool | registered tool |
| project | code surface agents work in |
| listen | runtime endpoint |
| hermes | harness runtime |

## Forge voice

Maps/predictions/inventions are written as **agent capability products**, not generic ops essays.
